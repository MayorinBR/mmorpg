# Swordman — Class Reference

Source: [iRO Wiki Classic — Swordman](https://irowiki.org/wiki/Swordman), consulted September 2026. This document is the first of a planned per-class series (see `MMO_Project_GDD.docx`, Section 10.1) — it exists to keep the real Ragnarok Online reference and this project's own implementation status next to each other, so future class work doesn't need to re-derive it.

## Overview

Base class, no promotion yet available in this project (class evolution — e.g. Swordman to Knight/Crusader — is tracked as planned but undesigned; see `PlayerClassController.ChangeClass`). In classic Ragnarok Online, Swordman is a Human-only class that job-changes from Novice at the Izlude guild, with a Job Level cap of 50. Design identity: a durable melee fighter built around high ATK and HP rather than evasion — "offense as defense."

Currently implemented in this project: the basic-attack block chance (`PlayerBlockController`, an `IDamageModifier` hook — 25% chance, full negation by default, tunable per prefab), the Bash, Magnum Break, Sword Mastery, Two-Handed Sword Mastery, Provoke, Endure and Berserk skills below, the Job Level 50 stat bonus (see below), and the weapon-vs-monster-size damage table (see below).

## Stat Bonuses at Job Level 50

| STR | AGI | VIT | INT | DEX | LUK |
|-----|-----|-----|-----|-----|-----|
| +7  | +2  | +4  | +0  | +3  | +2  |

**Implemented this pass.** `ClassJobLevelBonusLookup.asset` grants this flat bonus automatically once Swordman reaches Job Level 50, folded into every derived stat by `JobBonusStatsView` (mirrors how `EquippedStatsView` folds in equipment bonuses) — separate from normal spendable stat points, matching real Ragnarok Online. Real RO grants this incrementally across multiple Job Level milestones; this project only has the final Job 50 total documented, so the bonus is a single cliff-edge grant at Job 50 rather than a staged curve — add intermediate breakpoints if the real per-level schedule gets sourced later.

## Skill Roster

| Skill | Real type / max level | Real effect | Status in this project |
|---|---|---|---|
| **Bash** | Offensive, Lv 1–10 | ATK ×130–400%, +5–50% accuracy | **Implemented.** Single-target physical damage (`Bash.asset`), max level 5 (project-wide skill level cap, not RO's 10). Now also grants a level-scaling Hit-rating bonus on its own damage roll (`SkillDefinition.GetAccuracyBonus`), matching the real accuracy bonus — tuned to reach the wiki's +50 upper value at this project's max level. |
| **Magnum Break** | Offensive, Lv 1–10 | Fire AoE, ATK ×120–300% to a 5×5 area | **Implemented this pass.** New `MagnumBreak.asset`: Fire-element physical damage to every living target within a radius of the caster, needing no pre-selected target at all (`SkillDefinition.IsAreaOfEffect` / `AreaRadius`, `PlayerSkillCaster.TryCastAreaDamage`) — this project's first area-of-effect skill. Damage curve tuned to reach the wiki's 300% upper value at this project's max level (5). No icon yet (see the shared skill-icon sprite sheet gap already tracked in the GDD). |
| **Provoke** | Active, Lv 1–10 | +5–32% target ATK, −10–55% target DEF (a taunt/debuff) | **Implemented this pass.** New `Provoke.asset`: an Enemy-targeted `SkillEffectType.Buff` skill applying a timed ATK-up/DEF-down modifier to the current target via `BuffController` (`PlayerSkillCaster.TryCastBuff`). `HealthComponent` reads the DEF debuff through the same optional-hook slot as its other defensive-stat sources; `EnemyAttackState` reads the ATK buff directly off `EnemyController.Buffs`. Real RO's 30s duration doesn't scale with level (sourced from iRO Wiki); the ATK/DEF percentages are linearly compressed to reach the wiki's level-10 values (+32%/−55%) at this project's level 5 cap, the same convention used for Bash's accuracy bonus. |
| **Endure** | Active, Lv 1–10 | Resists flinching for up to 7 hits / 10–37s, +1–10 MDEF | **Partially implemented this pass.** New `Endure.asset`: a Self-targeted `SkillEffectType.Buff` skill granting a timed flat MDEF bonus through the same `BuffController` used by Provoke — `HealthComponent.MagicalDefense` adds it directly. Duration is linearly compressed to reach the wiki's 37s at this project's level 5 cap, following the same convention as the ATK/DEF percentages above. The flinch-resistance half is **not implemented**: it's a hit-reaction/stagger mechanic, not a stat modifier, and this project has no such concept at all yet (see item 4 below) — a real hit lands on the player exactly the same whether Endure is active or not. |
| **Increase HP Recovery** | Passive, Lv 1–10 | Boosts natural HP regen and healing-item effectiveness by 10–100% | **Not implemented** — the passive-skill mechanic itself now exists (`SkillEffectType.Passive`, see Sword Mastery below), but this specific skill also needs a base HP-regen-over-time system, which still doesn't exist: `HealthComponent` only ever changes HP in response to `TakeDamage`/`Heal` calls, never on a timer. |
| **Sword Mastery** | Passive, Lv 1–10 | +4–40 ATK with swords and daggers | **Implemented this pass.** New `SwordMastery.asset`: a `SkillEffectType.Passive` skill (`PlayerPassiveSkillController` sums it into `PlayerStatsController.CurrentSubStats.StatusAtk` whenever learned) that only applies while the equipped main-hand weapon's new `ItemDefinition.WeaponSubtype` is Dagger or One-Hand Sword (`SkillDefinition.PassiveRequiredWeaponSubtypes`). Never appears on the hotbar — a passive skill is never cast. Bonus tuned to reach the wiki's 40 ATK upper value at this project's max level (5, so +8/level). |
| **Two-Handed Sword Mastery** | Passive, Lv 1–10 | +4–40 ATK with two-handed swords | **Implemented this pass.** New `TwoHandSwordMastery.asset`, identical mechanism to Sword Mastery above, gated on `WeaponSubtype.TwoHandSword` instead. `TestTwoHandSword.asset` now exists to equip and test it against — still a generic test item, not a curated itemization pass. |
| **Berserk** (quest skill, Job Lv 30) | Passive | +32% ATK, −55% DEF while under 25% HP | **Implemented this pass.** New `Berserk.asset`: a `SkillEffectType.Passive` skill whose ATK/DEF values reuse the Buff system's fields (`buffAtkPercentPerLevel`/`buffDefPercentPerLevel`) rather than the flat passive-ATK field, since its effect is a percentage modifier, not a flat Status ATK bonus. A new `PlayerBerserkController` watches `HealthComponent.HealthChanged` and applies/clears the modifier via `BuffController.SetPersistentModifier` — a persistent (not timed) entry, so repeated HP changes replace rather than stack it. `PlayerStatsController.CurrentSubStats` now also multiplies Status ATK by any attached `BuffController.AttackMultiplier`, a gap this uncovered: player ATK previously never read any buff (enemies already did, via `EnemyAttackState`). Real RO's Job Level 30 unlock requirement isn't modeled — this project has no Job Level unlock gate anywhere yet — so learning the skill is the only requirement. Max level 1 (single-rank skill, unlike this project's usual 5-level cap). |
| **Fatal Blow** (quest skill, Job Lv 30) | Passive | Bash (Lv 6–10) gains a chance to stun | **Not implemented** — needs a stun/status-effect system; this project has no status-effect system of any kind yet. |
| **HP Recovery While Moving** (quest skill, Job Lv 35) | Passive | Removes the usual HP-regen-while-moving penalty | **Not implemented** — same missing regen system as Increase HP Recovery. |

Weapon-vs-monster-size damage scaling is also real-RO Swordman behavior (relevant to its dagger/one-hand-sword/two-hand-sword kit specifically) and is **implemented this pass** — see item 5 below; it's a general combat mechanic, not Swordman-specific code, so it applies to every class's weapon the moment any of them get equipped.

## Missing Systems (grouped — one build unblocks several skills at once)

1. ~~Passive skill effects~~ — **implemented this pass.** `SkillEffectType` gained a `Passive` value (never cast — `PlayerSkillCaster.TryCastSkill` and the Skill Book's hotbar drag both refuse it); `PlayerPassiveSkillController` sums every learned passive's bonus on demand. Sword Mastery and Two-Handed Sword Mastery are the first skills to use it. Still doesn't unblock Increase HP Recovery or HP Recovery While Moving on its own — see item 3 below, still needed for those. Berserk (see the Skill Roster above) combines this with item 2's buff system instead, and is now implemented.
2. ~~Buffs/debuffs~~ — **implemented this pass.** `SkillEffectType` gained a `Buff` value; new `BuffController` holds temporary, timed ATK%/DEF%/MDEF modifiers on whichever character it's attached to, read by `HealthComponent` (defense) and `EnemyController`/`EnemyAttackState` (attack) the same optional-hook way equipment and Job Level bonuses already are. Provoke (Enemy-targeted) and Endure (Self-targeted, MDEF half only) are the first skills to use it — see the Skill Roster above. `BuffController` also gained `SetPersistentModifier`, a non-timed entry keyed by source that replaces rather than stacks — needed for Berserk, a condition-triggered (not cast) buff that would otherwise add a new timed entry every time its HP-threshold trigger re-evaluates. Reusable as-is for the other five classes' own buffs/debuffs once designed.
3. **HP regen-over-time** — a base "HP recovers gradually while idle/moving" system. Blocks Increase HP Recovery and HP Recovery While Moving. Doesn't exist at all today, for any class.
4. **Status effects** (stun, etc.) — blocks Fatal Blow. No status-effect system exists yet. A related but distinct gap: a hit-reaction/stagger (flinch) mechanic also doesn't exist, so Endure's "resists flinching" half stays unimplemented even with the buff system now in place — a landed hit never flinches the player today regardless, so there's nothing yet for Endure to suppress.
5. ~~Weapon subtypes + monster Size~~ — **implemented this pass, both halves.** Weapon subtypes cover every type on the [iRO Wiki weapon list](https://irowiki.org/wiki/Weapons): `ItemDefinition.WeaponSubtype` has Dagger, One/Two-Hand Sword, One/Two-Hand Axe, Mace, Spear, Bow, Book, Instrument, Whip, Rod, Knuckle, Katar, Gun and Huuma Shuriken, plus a project-specific `Shield` value for off-hand equipment with no attack of its own (this unblocked Sword Mastery vs. Two-Handed Sword Mastery). Monster Size is a new `CharacterStatsDefinition.Size` field (`MonsterSize`: Medium/Small/Large, Medium first so pre-existing assets default to it), and the weapon-vs-size damage table itself is a new `WeaponSizeModifiers.Apply(damage, category, weaponSubtype, targetSize)` — the single choke point both `PlayerCombatController.DealHit` (basic attacks) and `PlayerSkillCaster` (Physical skills, single-target and area) now call before `IDamageable.TakeDamage`, scaling only physical damage, leaving magical untouched, matching real Ragnarok Online. `IDamageable` gained a `Size` property so any attacker can read a target's size generically. Poring/Poporing (`PorigonStats.asset`/`PoporigonStats.asset`) are now explicitly tagged Small, matching real RO; every other existing enemy asset defaults to Medium (no penalty against a 1H sword, Swordman's most common weapon) until tagged otherwise.
6. ~~Class-specific Job Level stat bonuses~~ — **implemented this pass.** `ClassJobLevelBonusLookup` + `JobBonusStatsView` (see "Stat Bonuses at Job Level 50" above). Only Swordman's Job 50 entry is populated; add one per class as their real stat tables get researched.

Items 3-4 aren't Swordman-specific — each will very likely come up again for the other five classes, so building either now front-loads work rather than only unblocking Swordman. The two remaining Swordman gaps (Increase HP Recovery / HP Recovery While Moving, and Fatal Blow / Endure's flinch-resist half) are both blocked on one of these two systems each.
